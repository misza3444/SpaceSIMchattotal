# ADR 0001 — Minimal serializable component-bag ECS

Status: Accepted (Stage 0)

## Context

SpaceSim requires a headless, seeded simulation independent of Three.js/DOM. State must round-trip to IndexedDB and eventually allow high/low attention materialization. No present gameplay justifies a dense archetype engine.

## Decision

Use an internal component-bag ECS represented as a JSON array of entities. Each entity has a monotonically increasing numeric ID and optional `transform` and `motion` components. Commands and systems are the only writers, while UI and renderer obtain cloned snapshots. The simulation owns its RNG and event bus.

## Consequences

Easy migration, stable JSON shape, deterministic entity enumeration and straightforward testing. Lower performance than bitECS for very high counts; benchmark at Stage 5 and adopt archetypes if profiling proves necessary. No third-party ECS dependency yet.
