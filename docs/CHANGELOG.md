# Changelog

## 0.0.1 — Stage 0

- Initial TypeScript strict, Vite, Three.js, ESLint, Vitest structure in this standalone repository without altering the .NET desktop game.
- Pure deterministic 60Hz simulation, component-bag ECS, queued commands and typed event bus.
- IndexedDB save/load with envelope schema migration and tests.
- Zod-validated JSON catalogs with reference checks, PL/EN translations.
- Empty 3D renderer, debug HUD, headless CLI and CI definition.
